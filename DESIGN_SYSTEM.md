# LockifyHub Design System\n\nA comprehensive, production-ready design system inspired by Neighbor.com's modern aesthetic, built with accessibility, performance, and mobile-first principles.\n\n## 🎨 Design Philosophy\n\nOur design system follows these core principles:\n\n- **Accessibility First**: WCAG 2.1 AA compliance with keyboard navigation and screen reader support\n- **Mobile-First**: Responsive design that works beautifully on all devices\n- **Performance Optimized**: Lightweight components optimized for Core Web Vitals\n- **Neighbor.com Inspired**: Modern blue palette with clean, minimalist aesthetics\n- **User-Centric**: Intuitive interfaces that prioritize user experience\n\n## 🚀 Getting Started\n\n### Installation\n\nThe design system is built into LockifyHub using Tailwind CSS with custom configurations.\n\n### Quick Start\n\n```jsx\nimport { HeroSearch, ListingCard, ModernNavigation } from '../Design';\n\n// Use components with built-in design system\n<ModernNavigation variant=\"landing\" />\n<HeroSearch onSearch={handleSearch} />\n<ListingCard listing={data} variant=\"featured\" />\n```\n\n### View the Design System\n\n- **Design System Showcase**: Visit `/design-system` to see all components\n- **Modern Browse Page**: Visit `/browse-modern` to see the system in action\n- **Landing Page**: Visit `/` for the enhanced landing experience\n\n## 🎯 Core Components\n\n### Navigation\n\n**ModernNavigation** - Responsive navigation with multiple variants\n\n```jsx\n<ModernNavigation \n  variant=\"landing\"     // 'landing', 'default', 'dashboard'\n  user={userObject}     // User data for authenticated states\n  notifications={3}     // Notification count\n  onSignOut={handler}   // Sign out callback\n/>\n```\n\n### Hero Search\n\n**HeroSearch** - Location-based search with filters\n\n```jsx\n<HeroSearch \n  placeholder=\"Enter your location\"\n  onSearch={(location, filters) => {}}\n  showQuickFilters={true}\n/>\n```\n\n### Listing Cards\n\n**ListingCard** - Multiple variants for different use cases\n\n```jsx\n<ListingCard \n  listing={listingData}\n  variant=\"default\"        // 'default', 'featured', 'compact'\n  onFavoriteToggle={handler}\n  onBookingClick={handler}\n  onViewDetails={handler}\n/>\n```\n\n### Enhanced Search\n\n**EnhancedSearch** - Advanced filtering and sorting\n\n```jsx\n<EnhancedSearch \n  listings={data}\n  onResultsChange={handler}\n  onFilterChange={handler}\n/>\n```\n\n## 🎨 Design Tokens\n\n### Color Palette\n\n#### Primary (Neighbor.com Blue)\n```css\n--primary-50: #eef8ff   /* Lightest blue */\n--primary-500: #0079e1  /* Main brand blue */\n--primary-900: #003d72  /* Darkest blue */\n```\n\n#### Semantic Colors\n```css\n--success: #22c55e      /* Success states Responsive typography from 12px to 96px\n- **Line Heights**: Optimized for readability\n\n### Spacing\n\n- **System**: 4px base unit (0.25rem)\n- **Scale**: xs(8px) → sm(12px) → md(16px) → lg(24px) → xl(32px) → 2xl(48px)\n\n### Shadows\n\n```css\n--shadow-soft: 0 2px 15px -3px rgba(0, 0, 0, 0.07)     /* Subtle depth */\n--shadow-medium: 0 4px 25px -5px rgba(0, 0, 0, 0.1)     /* Standard cards
